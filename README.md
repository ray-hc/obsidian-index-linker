# Obsidian Index Linker

Sometimes, we want to link to a folder rather than a specific file. 

README or index.md files are often used for this purpose on the web. This plugin adds a command to select a folder, create an index page for that folder (based on customizable name pattern), and insert a link to the index on current folder.

I suggest supercharging with a plugin like `neighbouring-files`, so that after navigating to the index, you can move around the folder freely.
